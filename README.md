# DataChannlel-SDK-js
This is a javascript sdk for [AtelierUEDA Datachannel](https://datachannel.uedasoft.com)

## Install
### npm
```
npm install github:UedaTakeyuki/datachannel-sdk-js
```
### yarn
```
yarn add https://github.com/UedaTakeyuki/datachannel-sdk-js
```
### pnpm
```
pnpm add git+https://github.com/UedaTakeyuki/datachannel-sdk-js
```

## CDN
```
<script type="module"
  import * as DataChannel from　"https://cdn.jsdelivr.net/gh/uedatakeyuki/datachannel-sdk-js@main/src/index.js";
</script>
```
