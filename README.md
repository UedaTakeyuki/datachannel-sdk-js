# DataChannlel-SDK-js
This is a javascript sdk for [AtelierUEDA Datachannel](https://datachannel.uedasoft.com) that aims to provide Web application with P2P data connection out of the box.

## Install
### npm
```
npm install github:UedaTakeyuki/datachannel-sdk-js
```
### yarn
```
yarn add https://github.com/UedaTakeyuki/datachannel-sdk-js
```
### pnpm
```
pnpm add git+https://github.com/UedaTakeyuki/datachannel-sdk-js
```

## CDN
```
<script type="module"
  import * as DataChannel from　"https://cdn.jsdelivr.net/gh/uedatakeyuki/datachannel-sdk-js@main/src/index.js";
</script>
```

## Why this package is not available on npm
To publish to npm today, having a ***passkey*** is ***mandatory***, which forces developers to meet the strict environmental requirements imposed by big tech passkey providers.
However, my Mac—which ***lacks Touch ID***—cannot satisfy these hardware demands. More importantly, I struggle to see why we, as developers, must blindly conform to these somewhat self-serving mandates dictating our choice of hardware.
As a result, it pains me that I cannot provide the familiar npm install experience you are accustomed to. I deeply appreciate your understanding of my situation and stance.
